# USB-8-digit-Display
USB 8-digit Display HW and SW development , stretching the limits of what 7-segment LEDs can do by playing with phase and frequency.
We've managed to have different light intensity in each segment of each digit, so we were able to create several creative effects when displaying numbers or words.

- Manual EN Display USB.pdf - User Manual with some technical details
